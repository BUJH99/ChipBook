13-1. CMOS Inverter

CMOS Inverter 구조 및 동작

PMOS pull-up과 NMOS pull-down은 안정된 입력 상태에서 상보적으로 동작합니다. Gate는 Vin을 공유하고 drain은 Vout을 공유합니다. 입력이 바뀌는 동안에는 두 소자가 함께 전도할 수 있으며, 부하의 충전·방전과 순간 공급 전류를 함께 봅니다.

회로도와 출력 경로

전압 전달 특성 · VTC

Vout=VDD / [1+exp(20(Vin/VDD−center))]를 사용한 매끄러운 교육용 VTC입니다. VIL·VIH는 |slope|=1, VM은 Vout=Vin으로 계산합니다. VOL·VOH는 해당 입력 경계에서의 출력이며 NML=VIL−VOL, NMH=VOH−VIH입니다. SPICE나 library 보장값이 아닙니다.

Layout Cell 구조 · 같은 네 terminal의 평면 연결

PMOS는 N-well, NMOS는 P-substrate에 둔 개념 예입니다. 공통 poly가 두 active 영역을 가로지르고, active 바깥의 poly contact가 Vin과 연결됩니다. 왼쪽 source는 각 전원에, 오른쪽 두 drain은 Vout에 연결됩니다.

N-well tap은 VDD, substrate tap은 GND에 연결했습니다. Layer의 색과 치수는 설명용이며 특정 PDK의 DRC를 통과한 cell이 아닙니다.

VTC의 유효 low/high 입력 범위와 transition 구간을 구분합니다. VDD/2가 모든 inverter의 switching threshold인 것은 아니며, 실제 VM과 noise margin은 transistor 크기·model·PVT 조건에서 확인합니다.

13-4. 회로의 전력

CMOS 회로의 전력 구성

Switching 중 부하의 충전·방전, 입력 transition 중 PMOS/NMOS 동시 전도, 안정 상태에서도 남는 leakage를 구분합니다. 아래 회로는 각 전류 경로를 분리해서 보여 줍니다.

Dynamic · 충전과 방전

Vin 1→0 · Vout 충전

Vin 0→1 · Vout 방전

Short-circuit · 동시 전도

입력이 천이하는 구간에서 VDD에서 GND까지 전도 경로가 생길 수 있습니다.

Leakage · 안정 상태

Subthreshold, gate, junction leakage 등은 process·전압·온도·상태에 따라 달라집니다.

입력·출력·공급 전류의 시간 관계

Inverter의 입력 상승은 출력 부하를 방전하고, 입력 하강은 VDD에서 부하를 충전합니다. 두 edge의 순간 short-circuit 성분과 leakage baseline을 공급 전류에 더한 정규화 예입니다.

파형의 상대 높이·time constant는 경로 설명을 위한 가정입니다. 아래 power 계산의 측정 파형이나 transistor simulation 결과가 아닙니다. 방전되는 capacitor의 전류를 VDD charging current로 표시하지 않습니다.

전력 모델과 같은 workload의 비교

Pdyn = α · C · VDD² · f
Psc = Esc,event · revent
Pleak = VDD · Ileak

Psc의 event energy와 event rate는 별도로 주어진 모델 값입니다. 입력 slew·load·PVT를 모르면서 하나의 보편적인 계수로 추정하지 않습니다. 기본 dynamic power는 6.4 mW이며 특정 등가 capacitance 범위의 값입니다.

13-5. 저장 소자와 Clock 회로

Transmission-Gate Latch의 구조와 상태

입력 TG 뒤 두 inverter를 통과해 Q를 만들고, Q를 저장 node X로 되돌리는 TG가 값을 유지합니다. CLK가 high이면 입력을 통과시키고 low이면 feedback loop를 닫는 positive-level latch입니다.

TG latch 회로

동작 상태 선택

각 TG는 NMOS와 PMOS의 병렬 switch를 추상화한 기호입니다. 두 gate에 상보적인 control을 공급합니다. Feedback에 포함한 두 inverter가 정적 저장 loop를 형성합니다.

상승 edge Flip-Flop · Master–Slave

Low-level master와 high-level slave를 연결합니다. 상승 edge 직전에 master가 잡은 데이터가 slave를 통해 Q로 전달됩니다.

D · CLK · Q의 같은 시간 축

Q는 세 상승 edge에서 순서대로 1, 0, 1을 capture합니다. 이 이상적인 파형은 clock-to-Q 지연을 0으로 두었습니다.

Setup / Hold와 clock-to-Q

항목의미

검증Data path와 clock path의 실제 min/max 조건 평가

Timing window는 저장 소자의 정상 동작 조건입니다. Reset의 존재가 setup/hold, recovery/removal 조건을 없애지 않습니다.

Clock Gating · Enable을 low phase에 저장

단순 AND는 enable이 clock high 중 바뀌면 pulse를 자릅니다. ICG의 low-level latch는 high phase 동안 enable을 유지해 clock pulse 중간의 변경을 차단합니다.

이상적 logic timing 예입니다. 실제 ICG는 gating setup/hold, test enable, clock tree, library polarity를 확인합니다. 경계 시각의 비동기 입력이 안전하다는 의미가 아닙니다.

Inverter sizing과 부하를 바꾼 뒤 같은 입력에서 delay·slew·입력 C·출력 에너지를 비교합니다. 이 화면은 명시한 RC 수치 모델입니다. 실제 설계에서는 schematic → layout → DRC/LVS → PEX → 같은 testbench의 post-layout simulation으로 이어 갑니다.

설계 변수 · Transistor sizing와 load

기준 Wp=1.2 μm, Wn=0.6 μm, L=0.18 μm에서 Rp=Rn=10 kΩ로 둡니다. R은 L/W에 비례하고 Cin=3 fF/μm² × (Wp+Wn)L로 가정합니다. Model·corner characterization을 대신하는 값이 아닙니다.

DC 특성 · 추가 shunt C의 범위

이 모델에서는 output의 추가 R/C가 무부하 DC 전달 특성을 바꾸지 않습니다. 전후 VTC는 겹치므로 하나의 곡선으로 표시합니다.

VTC 중심은 가상 βp/βn 비율로 이동시키고 13-1의 sigmoid를 사용합니다. 실제 I–V 연립 해나 SPICE 계산이 아닙니다.

Transient · 같은 입력의 응답 비교

추가 RC 포함추가 RC 없음공통 Vin

각 반주기를 가장 느린 τ의 7배로 두어 settling을 비교합니다. 파란 곡선은 Rwire와 Cpara가 더해진 같은 driver입니다.

설계·검증 결과 비교

tp = ln(2) · R·C · slew₁₀–₉₀ = ln(9) · R·C
0→1 transition의 공급 energy = C · VDD²

표의 tp·slew는 완전히 settled된 step의 해석값입니다. Output C만 추가한 예이므로 input C는 변하지 않습니다. Leakage나 short-circuit 전력은 이 RC 모델에서 예측하지 않습니다.

Schematic·layout·model을 바꾸면 실행한 netlist와 결과의 버전을 함께 기록합니다. 회로 변경만으로 이전 simulation 결과가 갱신되지는 않습니다.
