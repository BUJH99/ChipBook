Sampling한 Vin을 유지하고, MSB부터 trial code를 DAC로 바꾸어 비교합니다. 샘플 신호와 DAC 기준은 comparator의 서로 다른 입력에 연결됩니다.

Binary-weighted capacitor array · 입체 구조 예

입체 그림은 4-bit 가중 capacitor 그룹 8C·4C·2C·C의 개념입니다. 아래 현재 N-bit SAR의 전체 capacitor 개수를 표현한 것이 아닙니다.

이미지에는 1C dummy가 생략되어 있습니다. 아래 연결도는 total 16C를 만드는 dummy까지 표시하며 switch와 comparator는 native 회로로 구분합니다.

SAR 변환과 code 오차

LSB = VREF / 2ᴺ
Code = floor(Vin / LSB)

Code는 0…2ᴺ−1로 포화하고 복원값은 bin 중앙을 사용합니다. 기본 8-bit, 1 V, Vin=0.72 V의 code는 184입니다. 12-bit, 1 V의 LSB는 약 244 μV입니다.

ENOB=(SINAD−1.76)/6.02는 full-scale sine 측정 SINAD를 입력한 결과입니다. 이 정적 transfer에서 noise나 distortion을 측정한 것이 아닙니다. Sampling bandwidth, anti-alias filter, reference noise·settling, DNL/INL은 별도 지표입니다.
