R–2R Ladder DAC · voltage mode

수평 저항은 R, 각 switched branch와 끝단 종단 저항은 2R입니다. 각 bottom switch를 VREF 또는 GND에 연결하면 가장 왼쪽의 high-impedance ladder output에 binary-weighted 전압이 만들어집니다.

이상적 transfer

Unity-gain buffer를 사용한 양의 voltage-mode 출력입니다. Inverting current-output DAC와 부호를 혼동하지 않습니다.

Analog Devices: current-mode와 voltage-mode R–2R 구조

이상적 동시 switching과 settling

모든 bit가 동시에 바뀐 뒤 1차 output filter를 통과한 응답과 최종 값 ±0.5 LSB를 표시합니다.

Bit switching skew에 의한 차이

모든 bit 동시 변경지정 순서 / skew 반영

Major carry에서는 중간 code가 목표에서 크게 벗어날 수 있습니다. 여기는 bit 변경 시간 차이만 계산하며 switch charge injection은 제외합니다.

Code와 실제 switch 상태

Bit 버튼은 목표 code를 직접 바꿉니다. N-bit 범위 밖의 숫자는 유효 최대 code로 제한합니다.

Skew 모델에서의 중간 code

표시한 settling 시각은 마지막 switch 이후 응답이 목표 ±0.5 LSB에 들어가는 시점입니다. 절대 차이 면적의 단위 V·μs는 이 모델의 waveform 차이이며 실제 소자의 보장 glitch impulse 수치가 아닙니다. 최종 DC 값만으로 빠른 waveform 생성 성능을 판단하지 않습니다.
