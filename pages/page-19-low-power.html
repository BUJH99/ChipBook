저전력 설계와 UPF

19-1. 전력 모델과 예산

Activity는 무엇을 세었는지 정의해야 하며 peak와 average는 다른 문제다. Block 수치를 합칠 때 중복 계상한 clock와 memory 영역을 확인한다.

계산·동작 예

αCV²f 모델로 dynamic 성분의 경향을 보고 leakage와 항상 켜진 영역의 비용을 더한다. 실제 측정과 모델 값은 구분해 표시한다.

짧은 idle 구간의 낮은 평균을 active workload의 전력으로 대표하지 않는다.

조건이 다른 전력 숫자를 직접 비교하지 않는다.

19-2. Clock Gating과 Operand Isolation

두 방법은 차단 위치와 제어 조건이 다르다. Enable의 유효 시간과 wake-up 후 상태 전달을 검증한다.

계산·동작 예

Register가 유지되어도 입력 조합회로가 계속 토글할 수 있다. 반대로 operand를 고정해도 clock tree는 계속 switching할 수 있어 어떤 활동을 줄이는지 구분한다.

단순 AND clock gating으로 glitch를 만들지 않도록 검증된 cell과 제약을 사용한다.

기능을 유지하면서 중지되는 활동을 설명한다.

19-3. Power Gating과 도메인

Power switch와 항상 켜진 제어, isolation, wake-up 전류와 안정 시간을 고려한다. Off domain의 출력이 on domain의 동작을 오염시키지 않아야 한다.

계산·동작 예

요청 정지와 완료 확인 후 isolation을 걸고 power를 끈다. 켤 때는 공급이 안정된 후 상태 복원과 reset 조건을 만족하고 isolation을 해제한다.

꺼진 domain의 register가 이전 값을 유지한다고 기대하지 않는다.

전원 없는 도메인의 출력을 통제한다.

19-4. Retention과 Level Shifter

Level shifter는 전압 domain 사이의 신호 수준을 변환한다. Isolation은 유효하지 않은 출력을 안전한 값으로 고정하는 별도 기능이다.

계산·동작 예

Power-off 전에 save가 끝났는지, power-on 후 restore와 reset의 우선순위가 맞는지 확인한다. Level shifter의 방향과 항상 켜져 있어야 하는 전원도 검토한다.

Retention cell을 넣었다는 이유로 모든 memory와 register가 자동 보존된다고 생각하지 않는다.

보존 대상·복원 순서·전압 변환을 구별한다.

19-5. DVFS와 Power State

낮은 전압에서는 허용 delay가 달라지므로 주파수와 함께 안전한 operating point를 정의한다. Regulator 안정 시간과 clock 전환·software 정책도 state transition의 일부다.

계산·동작 예

성능을 높일 때는 필요한 전압을 먼저 확보한 뒤 높은 주파수로 가는 순서를 검토한다. 낮출 때는 높은 주파수에서 낮은 전압을 거치는 순간이 없도록 한다.

Dynamic power의 제곱 법칙만 보고 전압을 임의로 낮추지 않는다.

전압/주파수 전환의 의존 조건을 확인한다.

19-6. UPF와 Power-Aware 검증

실제 구현과 simulation model이 이 의도를 어떻게 반영하는지 확인해야 한다. Power-aware 검증에서는 상태 전환과 X 전파, 경계 셀 동작을 함께 본다.

계산·동작 예

Off domain의 출력이 X가 될 때 isolation이 적용되어 on domain에 정의된 값이 전달되는지 확인한다. Save/restore 누락도 regression에 포함한다.

코드와 동작
