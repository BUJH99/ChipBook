주요 수 표현 형식의 bit 구성

부동소수점은 sign·exponent·fraction으로 범위를 표현하고, signed 정수는 정해진 bit 폭과 scale로 실수 값에 대응합니다. 연산과 저장에서 사용하는 형식을 각각 명시합니다.

FP32 · IEEE 754 binary32

필드역할
S0은 양수, 1은 음수
Exponent8 bit · bias 127
Fraction23 bit · 정규화 수의 숨은 1

FP16 · IEEE 754 binary16

필드역할
S1 bit
Exponent5 bit · bias 15
Fraction10 bit · 정규화 수의 숨은 1

INT8 · signed 2의 보수

항목의미
b₇가중치 −128
b₆…b₀가중치 64…1
범위−128…127, 총 256개

부동소수점 식은 정규화 수에 해당합니다. 0, subnormal, infinity와 NaN은 exponent / fraction의 별도 규칙을 따릅니다. INT8의 하위 bit를 부호와 분리된 절댓값으로 해석하지 않습니다.

양자화 수식과 zero-point

실수 x를 scale s > 0과 정수 zero-point z로 양자화합니다. 반올림 방식과 clipping 범위를 reference model과 hardware가 동일하게 사용해야 합니다.

q = clip(roundties-to-even(x / s) + z, qmin, qmax)
x̂ = s · (q − z)
기호계약
x양자화 전 실수 값
s양의 scale · 이 예제는 per-tensor
z해당 signed 범위 안의 정수
qmin / qmax−2^(b−1) / 2^(b−1)−1
반올림가장 가까운 정수 · 정확한 중간값은 짝수

수치 예와 saturation

기본 예는 x=3.7, s=0.25, z=0입니다. 14.8을 15로 반올림해 q=15, x̂=3.75, 오차=0.05가 됩니다. 표현 범위를 벗어나면 끝값으로 포화됩니다.

z=0이면 실수 0은 정수 0에 대응합니다. z≠0이어도 실수 0을 표현하는 정수는 z입니다. −128…127 범위 자체는 바뀌지 않습니다.

Signed bit를 줄였을 때 zero-point가 새 범위를 벗어나면 입력 오류를 표시합니다.

입력·복원값과 복원 오차

왼쪽은 입력 x에 대한 원래 값 y=x와 복원값 x̂입니다. 오른쪽은 같은 입력에 대한 x̂−x를 표시합니다. Clipping이 없는 범위의 반올림 오차는 대체로 ±s/2 이내이며, saturation에서는 더 커질 수 있습니다.
