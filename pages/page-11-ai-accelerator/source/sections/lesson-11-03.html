MAC Processing Element 구조

MAC은 곱셈과 누산을 수행합니다. PE는 operand register, local storage, valid·ready와 clear·reset 제어를 결합해 수락한 입력의 결과만 보관합니다.

구성 블록의 역할을 설명하는 입체 개념도이며 실제 cell 배치나 공정 stack을 뜻하지 않습니다.

Signed 부분곱과 가산 트리

8-bit 2의 보수 B의 최상위 bit는 음의 가중치를 가집니다. 아래는 pp[0…6] = A·bᵢ·2ⁱ, pp[7] = −A·b₇·2⁷로 분해한 산술 모델이며, 합계가 실제 A×B와 일치합니다.

수락 cycle과 accumulator

valid와 ready가 모두 1인 cycle만 누산합니다. Bubble과 stall은 같은 곱을 반복해서 더하지 않으며, 마지막 −1×6을 수락하면 19에서 13으로 바뀝니다.

코드와 동작

// cycle contract: accept = valid && ready
// A/B are signed; product and accumulator widths are explicit.
if (reset) {
    accumulator = 0;
    output_valid = false;
} else if (clear) {
    accumulator = 0;
} else if (accept) {
    accumulator += signed_product(a, b);
}

우선순위는 reset → clear → accept입니다. Product는 부호 확장하고 accumulator overflow 처리 방식을 별도로 정의합니다.

곱셈 입력 정밀도와 부분곱 값

정수 A/B는 위 부분곱 그림에 사용하고, 실수 A/B는 선택한 bit 폭과 scale로 양자화한 뒤 곱합니다. 두 입력을 zero-point 0으로 양자화했으므로 곱의 복원 scale은 s²입니다.

행렬 곱과 한 PE의 dot product

출력 C[i,j]는 A의 i번째 row와 B의 j번째 column을 곱해 합한 값입니다. 아래 두 행렬과 출력 위치를 바꾸면 각 k의 product와 누적합을 확인할 수 있습니다.
