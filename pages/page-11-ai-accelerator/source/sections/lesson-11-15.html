작은 NPU의 전체 구성과 확장 경계

먼저 작은 정수 GEMM core를 정확하게 계산하고, 이후 scratchpad·DMA·register·IRQ를 추가합니다. 아래는 확장 목표의 subsystem 구조이며, 다운로드하는 현재 SystolicCore는 parallel matrix port와 start/busy/done을 제공하는 계산 core입니다.

현재 다운로드 core의 실제 포트 계약

SystolicCore.sv의 구현을 기준으로 정리했습니다. 현재 core에는 MMIO register map, DMA 또는 IRQ controller가 포함되지 않으며, 별도 subsystem wrapper를 확장할 때 추가합니다.

포트 / parameter계약
P_SIZE2…4의 N×N 행렬
iClk / iRstn상승 edge · active-low asynchronous reset
iStartIdle에서만 수락 · A/B latch · C clear
iStepEnRUN에서 1일 때 logical cycle 진행
iMatrixA / iMatrixBSigned INT8 parallel matrix ports
oMatrixCSigned INT32 누적 결과
oBusyRUN 상태
oDone마지막 유효 cycle을 처리한 edge 후 한 clock pulse

Parallel matrix port는 교육용 경계이며 SRAM PHY가 아닙니다. Start를 수락한 edge와 첫 MAC을 수행하는 edge를 구분합니다.
