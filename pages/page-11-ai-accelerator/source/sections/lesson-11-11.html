Attention의 기본 흐름

Query와 Key의 유사도를 계산하고 mask·softmax를 거친 가중치로 Value를 합합니다. 각 query row의 softmax 합은 1이며, score shape와 output shape를 구분합니다.

구조 그림의 grid는 축의 대응을 설명합니다. 아래 수치 예는 작은 Q/K/V 행렬을 실제 계산하며 causal mask 선택을 결과에 반영합니다.

KV cache의 동작과 메모리 증가

Prefill은 여러 입력 token의 K/V를 준비합니다. Decode는 새 token의 K/V를 추가하고 기존 K/V를 재사용합니다. 저장 용량과 매 token에서 읽는 traffic은 서로 다른 지표입니다.

KV cache 용량

K와 V를 합한 단순 저장량입니다. GQA/MQA에서는 query head 수가 아니라 실제 KV head 수를 사용합니다.

Q: 2×2, K/V: 3×2 예입니다. Score는 QKᵀ/√2에 선택한 배수를 곱하며, causal mask는 query row r에서 key column c>r을 제외합니다. 결과는 표시를 위해 소수점 셋째 자리까지 반올림합니다.
