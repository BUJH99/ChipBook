Roofline에서 실제 성능까지

Arithmetic intensity는 선택한 memory 경계의 연산 수를 이동 byte로 나눈 값입니다. Compute peak와 memory bandwidth가 만드는 두 상한 중 작은 값이 성능 상한입니다. 실제 실행에는 제어·stall·tail·fill/drain 비용이 더해집니다.

모든 값은 입력 조건에서 계산한 모델 결과입니다. 측정값으로 표시하지 않으며, 실제 stall counter·queue occupancy·전송 byte를 통해 모델과 차이를 설명합니다.

동작 조건과 전력 모델

동적 전력 αCV²f와 누설 VI를 계산합니다. 아래 block 분해는 모델 예산이며 capacitance를 Compute/SRAM/NoC/Control에 45/35/12/8%, leakage current를 40/30/20/10%로 배분한다는 가정입니다.

이 capacitance / current 예는 작은 on-chip 블록 집계의 교육용 입력입니다. 전체 NPU·DRAM·보드 전력을 대표하지 않으며 short-circuit, regulator loss와 온도 의존성은 포함하지 않습니다.
