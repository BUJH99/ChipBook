Reuse가 절약하는 경계

Output-stationary·weight-stationary·input-stationary는 어느 값을 local storage에 오래 유지하는지 설명합니다. Systolic 연결 구조와 dataflow는 같은 말이 아니며, 각 방식에는 operand와 partial sum을 이동시키는 매핑이 필요합니다.

Output-stationary · OS

각 PE가 한 C[i,j]의 partial sum을 유지하고 K 방향으로 누산합니다.

Weight-stationary · WS

PE 안의 W[k,j]를 유지합니다. A를 공급하고 K 방향으로 partial sum을 모읍니다.

Input-stationary · IS

PE 안의 A[i,k]를 유지합니다. B를 공급하고 K 방향으로 partial sum을 모읍니다.

대표적인 4×4 logical mapping을 보여 주는 개념도입니다. Stationary 값은 PE 내부 register에 표시했으며, 출력 수집과 multicast의 구현은 실제 array 구조에 따라 달라집니다.

Stationary 값과 local 경계의 이동량

아래 count는 inter-PE multicast가 없고 stationary object 하나가 전부 local storage에 들어가는 scalar 경계 모델입니다. A/B는 INT8, C는 INT32로 계산합니다. 각 접근은 read 또는 write 한 번이며 DRAM traffic 예측값은 아닙니다.

OS: A=B=MKN, C=MN. WS: B=KN, A=MKN. IS: A=MK, B=MKN. WS/IS의 C 접근은 MN(2K−1)로 정의합니다.

Row-stationary의 배치와 재사용

Row-stationary는 convolution row의 dot product를 PE에 배치하고 filter·activation·partial sum의 재사용을 저장 계층과 통신에 함께 조직합니다. 위 RS 예는 한 output의 세 row contribution을 설명하며, 전체 Eyeriss energy simulator가 아닙니다.
