Boundary scan cell은 chip pin 경계의 제어·관측을 제공한다. CPU debug 기능은 JTAG transport를 사용할 수 있지만 boundary scan과 동일한 기능은 아니다.

계산·동작 예

보드 연결 검사에서 한 장치의 output boundary cell을 설정하고 상대 input cell로 관측한다. Functional logic을 실행하지 않고도 특정 연결 문제를 검사할 수 있다.

JTAG 연결이 있다는 것만으로 모든 debug register에 접근 가능하다고 가정하지 않는다.

경계 스캔과 일반 CPU debug 접근을 구별한다.
