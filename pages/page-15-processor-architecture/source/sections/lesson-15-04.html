TLB는 주소 변환 결과를 cache하는 구조이며 data cache와 역할이 다르다. 다중 agent의 cache coherence와 memory ordering은 계층 구조와 함께 검토한다.

계산·동작 예

4-line direct-mapped cache, 16-byte line에서 주소 0과 64는 같은 index에 대응하므로 서로 다른 tag가 교체된다. 가까운 주소라도 line boundary를 넘는지 확인한다.

Cache miss를 모두 DRAM 접근으로 간주하면 다른 cache level과 prefetch 등의 경로를 생략하게 된다.

주소 변환과 캐시 일관성을 구별한다.
