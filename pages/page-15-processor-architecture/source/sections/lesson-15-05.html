Branch divergence와 memory access 패턴은 실제 활용률에 영향을 준다. Memory coalescing은 인접한 요청을 효율적인 transaction으로 모으는 것과 관련된다.

계산·동작 예

Thread들이 연속 주소를 읽는 경우와 stride가 큰 주소를 읽는 경우를 비교한다. 필요한 payload가 같아도 실제 memory transaction 수는 달라질 수 있다.

Thread 수가 많다는 사실만으로 모든 연산기가 항상 유효한 일을 한다고 가정하지 않는다.

병렬화 수준과 실제 효율 차이를 설명한다.
