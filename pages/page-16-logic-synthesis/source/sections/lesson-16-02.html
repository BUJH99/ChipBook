생성 clock은 실제 원천과 관계를 정의해야 한다. IO delay는 칩 밖의 launch/capture와 board 조건을 내부 timing 분석에 연결한다.

계산·동작 예

Clock period를 정한 뒤 input delay와 output delay를 외부 소자·배선 예산에서 계산한다. 누락된 endpoint와 unconstrained path를 별도로 확인한다.

코드와 동작

# 아래 값은 설명용 가정입니다. 실제 설계의 IO 예산으로 바꾸세요.
create_clock -name clk -period 10 [get_ports clk]
set_input_delay  -clock clk -max 2.0 [get_ports data_in*]
set_input_delay  -clock clk -min 0.2 [get_ports data_in*]
set_output_delay -clock clk -max 1.0 [get_ports data_out*]
set_output_delay -clock clk -min -0.1 [get_ports data_out*]
# 단위와 실제 보드/외부 소자의 max/min 예산을 확인하세요.

제약이 없어서 violation이 없다는 결과를 timing 성공으로 읽지 않는다.

모든 timing endpoint의 가정을 명시한다.
