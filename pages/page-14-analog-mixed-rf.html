NMOS Current Mirror와 동작점

Reference branch의 diode-connected M1이 gate bias를 정합니다. M2는 같은 gate를 쓰지만 output drain이 외부 load에 연결되며, Iout은 VDS·geometry ratio·mismatch에 영향을 받습니다.

Output characteristic과 compliance

소자 매칭과 오차의 원인

ABBA unit 배치와 공통 gate

1:1 unit 배치의 예입니다. 비율이 다른 mirror는 unit 수와 centroid를 다시 설계합니다.

정한 reference tempco의 영향

M2 threshold 차이의 영향

Common-centroid는 특정 공간 gradient의 민감도를 줄입니다. Random mismatch, drain voltage, routing, contact와 주변 환경의 차이까지 모두 제거하지는 않습니다.

Bias mirror의 입력과 headroom

입력한 IREF와 geometry ratio를 유지하면서 output voltage와 overdrive를 바꿉니다. Vout이 effective overdrive보다 낮아지면 이 모델에서 M2는 triode로 이동합니다.

VGS₁ = Vth + Vov · Vth=0.4 V 가정
Iout,sat = ratio · IREF(T) · (Vov₂/Vov₁)² · (1+λVout)/(1+λVGS₁)

IREF(T)=IREF(25 °C)[1+TC(T−25 °C)]입니다. 온도 효과는 여기서 지정한 reference tempco만 반영합니다. Triode는 같은 square-law의 2x−x² 비율(x=Vout/Vov₂)로 연결합니다. Mobility·body effect·실제 reference start-up은 별도 검증합니다. 안정 동작점이 존재한다고 전원 인가 시 반드시 그 점으로 시작하는 것은 아닙니다.

14-3. 증폭기와 Comparator

Differential pair와 single-ended output

NMOS 입력쌍의 전류 차이를 PMOS mirror load가 한 출력으로 합치는 예입니다. 왼쪽 Vin+가 증가하면 출력 쪽 pull-up 전류가 상대적으로 커지는 극성으로 표시했습니다.

Tail current, input common-mode와 output headroom이 동작 범위를 정합니다. M3의 diode node를 두 번째 독립 output으로 취급하지 않습니다.

증폭과 비교의 전달 특성

연속 amplifier 개념Comparator 개념

두 tanh 곡선은 선형 증폭 구간과 빠른 판정 구간의 역할을 비교하는 가상 transfer입니다. 실제 comparator의 regeneration·offset·hysteresis를 계산한 결과는 아닙니다.

Small-signal gain · 같은 동작점

선택한 각 branch ID와 Vov로 gm≈2ID/Vov를 계산합니다. Output resistance는 ron과 rop의 병렬값을 사용합니다.

Comparator switching waveform

Vin은 VREF를 중심으로 20 mV peak, 1 MHz인 sine입니다. 비교기는 0.05 μs의 설정 가능한 전파 지연을 둔 판정 모델입니다.

비반전 feedback과 회로 파라미터

Ad ≈ gm(ron || rop)
Acl = A0/(1+A0β) · β=Rg/(Rf+Rg)

Op-amp를 comparator로 쓰거나 comparator를 linear feedback 안에 넣으면 recovery·speed·stability 조건이 달라집니다. Gain 식만으로 입력·출력 범위나 안정도를 보장하지 않습니다.

14-4. Feedback와 안정도

Negative feedback loop와 divider

출력의 일부를 Rf/Rg divider로 negative input에 되돌립니다. Low-frequency gain은 줄어들지만 signal range·linearity·bandwidth·stability 조건을 함께 평가합니다.

L(s)=A(s)β
A(s)=A0 / [(1+s/ω₁)(1+s/ω₂)]

Loop gain의 Bode와 phase margin

파랑은 |Aβ|, 빨강은 그 위상입니다. Phase margin은 unity loop gain 주파수에서 −180°까지 남은 각도로 표시합니다.

같은 loop 모델의 step response

부하 capacitance는 output pole ω₂=1/(Rout·CL)에 반영합니다. 선택한 CL와 다섯 배 CL를 같은 A0·dominant pole·feedback ratio에서 비교합니다.

선택한 CLCL × 5

14-5. Noise와 Mismatch

Matched devices와 정적 mismatch

같은 layout을 갖는 두 소자도 threshold와 전류 계수에 차이가 생길 수 있습니다. 대칭 배치가 줄이는 공간 gradient와 개별 소자의 random mismatch를 구분합니다.

σ(ΔVth,pair) = Avt / √(W·L)

이 페이지에서는 Avt를 pair-difference 계수로 정의합니다. 단위는 mV·μm, W와 L은 μm입니다. PDK마다 계수와 model의 정의를 확인해야 합니다.

작은 입력쌍에서는 ΔVth가 input offset에 기여하지만 회로의 전체 offset은 부하·bias·routing 등의 영향도 포함합니다.

주요 잡음원과 입력 환산 모델

입력에 등가 전압 잡음원을 놓아 회로와 시스템의 noise 예산을 연결합니다. 서로 독립인 잡음은 전압을 직접 더하지 않고 variance를 더합니다.

14-6. ADC

SAR ADC의 sample · compare · update

Sampling한 Vin을 유지하고, MSB부터 trial code를 DAC로 바꾸어 비교합니다. 샘플 신호와 DAC 기준은 comparator의 서로 다른 입력에 연결됩니다.

Binary-weighted capacitor array · 입체 구조 예

입체 그림은 4-bit 가중 capacitor 그룹 8C·4C·2C·C의 개념입니다. 아래 현재 N-bit SAR의 전체 capacitor 개수를 표현한 것이 아닙니다.

이미지에는 1C dummy가 생략되어 있습니다. 아래 연결도는 total 16C를 만드는 dummy까지 표시하며 switch와 comparator는 native 회로로 구분합니다.

Capacitive DAC의 전기적 연결

4-bit 예의 shared top plate와 독립 bottom switch 보기

Top plate의 초기 전하를 0으로 준비한 뒤 bottom plate 전압을 바꿀 때의 이상적 charge redistribution입니다. Sample phase의 switch 구성과 실제 parasitic은 별도로 설계합니다.

Successive approximation · 실제 trial 값

Trial DAC보존한 code의 DACSample Vin

Bit별 판정과 보존된 code

SAR 변환과 code 오차

LSB = VREF / 2ᴺ
Code = floor(Vin / LSB)

Code는 0…2ᴺ−1로 포화하고 복원값은 bin 중앙을 사용합니다. 기본 8-bit, 1 V, Vin=0.72 V의 code는 184입니다. 12-bit, 1 V의 LSB는 약 244 μV입니다.

ENOB=(SINAD−1.76)/6.02는 full-scale sine 측정 SINAD를 입력한 결과입니다. 이 정적 transfer에서 noise나 distortion을 측정한 것이 아닙니다. Sampling bandwidth, anti-alias filter, reference noise·settling, DNL/INL은 별도 지표입니다.

14-7. DAC

R–2R Ladder DAC · voltage mode

수평 저항은 R, 각 switched branch와 끝단 종단 저항은 2R입니다. 각 bottom switch를 VREF 또는 GND에 연결하면 가장 왼쪽의 high-impedance ladder output에 binary-weighted 전압이 만들어집니다.

이상적 transfer

Unity-gain buffer를 사용한 양의 voltage-mode 출력입니다. Inverting current-output DAC와 부호를 혼동하지 않습니다.

Analog Devices: current-mode와 voltage-mode R–2R 구조

이상적 동시 switching과 settling

모든 bit가 동시에 바뀐 뒤 1차 output filter를 통과한 응답과 최종 값 ±0.5 LSB를 표시합니다.

Bit switching skew에 의한 차이

모든 bit 동시 변경지정 순서 / skew 반영

Major carry에서는 중간 code가 목표에서 크게 벗어날 수 있습니다. 여기는 bit 변경 시간 차이만 계산하며 switch charge injection은 제외합니다.

Code와 실제 switch 상태

Bit 버튼은 목표 code를 직접 바꿉니다. N-bit 범위 밖의 숫자는 유효 최대 code로 제한합니다.

Skew 모델에서의 중간 code

표시한 settling 시각은 마지막 switch 이후 응답이 목표 ±0.5 LSB에 들어가는 시점입니다. 절대 차이 면적의 단위 V·μs는 이 모델의 waveform 차이이며 실제 소자의 보장 glitch impulse 수치가 아닙니다. 최종 DC 값만으로 빠른 waveform 생성 성능을 판단하지 않습니다.

14-8. PLL과 DLL

PLL · reference와 divided feedback

PLL은 출력 clock을 N으로 나눈 feedback을 reference와 비교해 oscillator를 제어합니다. Integer-N의 lock 주파수 조건은 fOUT=N×fREF, fFB=fREF입니다.

위상 차이와 정착한 clock

왼쪽은 같은 주파수에서 phase offset이 있는 초기 예, 오른쪽은 정착한 이상적 관계입니다. VCO 출력과 분주된 feedback clock을 구분합니다.

선형 loop의 주파수 응답

Open loop LReference transfer HSensitivity S=1−H

여기는 H(s)=ωn²/(s²+2ζωn s+ωn²), L=H/(1−H)인 선형 phase 모델입니다. Reference와 VCO noise의 전달 경로는 서로 다릅니다.

Matching network와 LNA, real mixer, IF filter를 거쳐 관심 주파수 대역을 변환합니다. 아래 spectrum은 설정한 단일 tone의 선 스펙트럼이며 noise floor 측정 결과가 아닙니다.

50 Ω reference의 matching 예

고정된 100 Ω 저항 부하를 선택한 RF frequency에서 50 Ω로 맞추는 이상적 L-network입니다. 두 reactive 소자의 값과 Γ를 같은 impedance 모델에서 계산합니다.

그래프는 20 log₁₀|Γ|이며 0 이하입니다. Return loss를 양수로 정의하면 부호가 반대입니다. Ideal 부품·저항 부하 가정으로, package·loss·device stability·광대역 matching을 포함하지 않습니다.

RF chain의 gain과 noise budget

Ftotal = F₁ + (F₂−1)/G₁ + (F₃−1)/(G₁G₂) + …

Gain G와 noise factor F를 선형 power 비율로 바꾸어 Friis 식에 넣고, 마지막에 dB로 환산합니다. 앞단 손실과 noise는 후단 gain으로 사라지지 않습니다.

Mixer 입력과 실제 통과 대역

Real mixer의 |fRF−fLO|와 fRF+fLO 성분을 계산합니다. 여기서는 6 dB conversion loss의 예와 통과 대역 gain 0 dB인 ideal low-pass를 사용합니다.

Mixer NF=6 dB, unity-gain active IF filter NF=2 dB는 예산 계산의 가정입니다. Filter 밖의 tone은 제거하며 image rejection·I/Q imbalance·compression·IIP3는 여기서 계산하지 않습니다. S-parameter는 정한 reference impedance와 frequency의 진행파 관계를 표현합니다.

14-10. 전력 IC와 센서 인터페이스

센서에서 변환기까지의 signal / supply 경로

Sensor AFE는 작은 신호의 bias를 정하고 증폭·필터링한 뒤 ADC에 전달합니다. Power IC의 supply 경로는 signal node와 분리되어 있으며 전원 noise·ripple도 측정 성능에 영향을 줍니다.

물리량 → 작은 전기 신호 · 센서 형태의 개념 예

LDO와 Buck의 같은 출력 부하

Pass-element 손실과 quiescent current를 포함한 LDO budget을 계산합니다. Buck 효율은 입력한 측정·설계 가정으로 두고, 그 값에서 input power와 loss를 구합니다.

14-12. Mixed-Signal 검증

Mixed-signal 경계와 검증 구성

Analog 입력이 sample과 quantization을 거쳐 digital code로 전달되는 경계와 latency·reset·power 계약을 함께 봅니다. Comparator의 단일 threshold와 ADC의 full-scale VREF는 서로 다른 파라미터입니다.

ADC box는 transfer와 latency를 표현하는 behavioral model입니다. Comparator 뒤의 1-bit 값을 다시 ADC에 넣는 직렬 경로가 아닙니다.

같은 입력에서 나온 analog waveform과 digital event

0.5 μs마다 sample하고 설정한 conversion latency 뒤 DATA/VALID를 갱신합니다. Reset은 0.4 μs에 해제되는 예이고, comparator의 관측 지연은 0.05 μs로 고정했습니다.

입력 조건과 DC code 확인

ADC transfer · DC 확인점

DC 확인표는 선택한 waveform과 별도로 입력한 Vin을 비교합니다. Model power OFF에서는 timing diagram의 conversion event와 VALID가 발생하지 않습니다. 데이터 형식·latency·범위만 보존하는 이상적 모델이며, 빠른 모델에서 생략한 analog 현상이 검증됐다고 해석하지 않습니다.
