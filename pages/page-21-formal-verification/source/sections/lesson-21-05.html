Register retiming이나 encoding 변경은 단순 node matching을 넘어서는 대응이 필요할 수 있다. ECO 뒤에는 변경 범위뿐 아니라 주변 영향도 확인한다.

계산·동작 예

기능 ECO가 아닌 timing ECO에서 동일 입력·초기 상태의 결과를 비교한다. Black box와 unmatched point가 결과를 얼마나 제한하는지 함께 읽는다.

코드와 동작

// Example comparison point; reset/initial-state relation is part of the proof.
assert_same_output: assert property (
    @(posedge iClk) disable iff (!iRstn)
    RefValid && ImplValid |-> RefData == ImplData
);
// This checker alone is not a complete sequential-equivalence proof.

이름이 같은 register가 반드시 같은 의미의 상태라고 가정하지 않는다.
