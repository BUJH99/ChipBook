DFT와 생산 테스트

20-1. Fault Model과 Testability

Stuck-at과 transition 같은 fault model은 실제 결함을 검사 가능한 행동으로 추상화한다. Fault coverage는 어떤 fault 집합을 분모로 삼았는지 함께 읽어야 한다.

계산·동작 예

내부 node가 stuck-at-0일 때 그 node를 1로 만들고 영향이 관측점까지 전달되도록 입력을 선택한다. 단순히 많은 random pattern을 넣는 것과 다르다.

제조 테스트의 높은 fault coverage를 기능 사양 전체의 검증 완료로 해석하지 않는다.

설계 버그 검증과 제조 결함 검사를 구별한다.

20-2. Scan 구조

Shift와 capture는 목적·clock·mode 조건이 다르다. Clock/reset 제어와 여러 domain 경계, lockup 구조의 필요성을 함께 검토한다.

계산·동작 예

Pattern을 shift-in → functional capture → response shift-out으로 진행한다. Capture 시점에 결함 효과가 저장되도록 조합경로를 활성화한다.

Scan enable 전환과 clock 제약을 생략하면 정상 scan cell도 잘못된 값이 들어갈 수 있다.

scan mode와 functional mode의 연결을 추적한다.

다음 절 · ATPG와 Coverage

20-3. ATPG와 Coverage

Untestable·aborted·excluded fault의 구분이 coverage 해석에 중요하다. Compression은 tester data와 test 시간을 줄이지만 추가 논리와 X 관리가 필요하다.

계산·동작 예

총 modeled fault와 검출·증명된 untestable·미해결 fault를 구분한 보고서를 읽는다. Coverage 분모에서 제외한 항목은 근거를 남긴다.

Excluded fault를 늘려 percentage만 높이지 않는다.

coverage 분모와 미검출 분류를 명시한다.

다음 절 · Memory BIST와 Repair

20-4. Memory BIST와 Repair

March 알고리즘은 주소 방향과 동작 조합으로 특정 fault 행동을 관측한다. Repair는 spare row/column 같은 자원을 사용하며 분석과 영구 설정 방식이 필요하다.

계산·동작 예

모든 주소에 0을 쓴 뒤 읽고 1로 바꾸는 단계에서 stuck fault와 transition 문제를 생각한다. 같은 값만 계속 쓰는 test로는 모든 coupling fault를 검출할 수 없다.

BIST pass와 장기 retention·모든 PVT 신뢰성 검사를 동일하게 보지 않는다.

메모리 결함을 검출하고 수리 자원을 배정한다.

다음 절 · JTAG와 Boundary Scan

20-5. JTAG와 Boundary Scan

Boundary scan cell은 chip pin 경계의 제어·관측을 제공한다. CPU debug 기능은 JTAG transport를 사용할 수 있지만 boundary scan과 동일한 기능은 아니다.

계산·동작 예

보드 연결 검사에서 한 장치의 output boundary cell을 설정하고 상대 input cell로 관측한다. Functional logic을 실행하지 않고도 특정 연결 문제를 검사할 수 있다.

JTAG 연결이 있다는 것만으로 모든 debug register에 접근 가능하다고 가정하지 않는다.

경계 스캔과 일반 CPU debug 접근을 구별한다.

20-6. ATE와 테스트 인계

Wafer sort와 packaged-device final test는 검사 시점과 접근 조건이 다르다. Binning과 test time은 품질·수율·비용에 연결된다.

계산·동작 예

같은 logic pattern도 tester의 drive와 compare timing, pin level 조건이 다르면 결과가 달라진다. 설계 pattern의 시간 기준을 tester 규격으로 변환한 근거를 확인한다.

Tester에서 fail이 났다는 이유만으로 즉시 silicon 불량으로 결론 내리지 않는다.

검사 비용과 품질을 함께 판단한다.
