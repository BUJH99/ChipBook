26-1. UART와 SPI Peripheral

RTL과 register, testbench와 driver가 같은 의미를 사용해야 한다. Normal path 이후 경계와 잘못된 설정을 검증한다.

계산·동작 예

26-2. APB 또는 AXI-Lite IP

주소·data·response의 수락 시점과 wait/error 동작을 분리한다. AXI-Lite에서는 write address와 data가 독립적으로 도착할 수 있다.

계산·동작 예

W1C status와 start command, read-only counter를 가진 작은 IP를 구성한다. Register side effect가 handshake당 한 번만 실행되는지 확인한다.

# RW with byte strobe 0101: 0x11223344 + 0xAABBCCDD -> 0x11BB33DD

26-3. FIFO와 DMA Subsystem

Queue에서 읽은 데이터가 실제 downstream에 수락될 때까지 보존되어야 한다. Descriptor wrap, partial last beat, timeout·reset의 상태를 정의한다.

계산·동작 예

Length가 beat 폭의 배수가 아닌 18 byte이고 beat가 4 byte이면 마지막 수락은 2 byte다. 유효 byte mask와 remaining count가 일치해야 한다.

코드와 동작

26-6. RTL부터 Physical 또는 FPGA까지

FPGA와 ASIC physical 경로는 서로 다른 제약과 완료 조건을 갖는다. 재현 방법과 남은 제한을 결과에 붙인다.

계산·동작 예

동일 RTL을 합성하고 timing·resource를 검토한 뒤 hardware 또는 layout 경로에서 관측한 결과를 정리한다. 사용하지 않은 실제 signoff 단계를 완료로 표시하지 않는다.

코드와 동작
