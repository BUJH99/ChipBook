BTI/HCI·EM·TDDB·ESD·latch-up은 원인과 검사 조건이 다르다. 가속 시험에서 사용 조건으로 해석할 때 모델과 적용 범위를 명시한다.

계산·동작 예

높은 온도나 전압에서 얻은 변화율을 사용 환경으로 옮기려면 해당 고장 메커니즘에 적합한 모델이 필요하다. 단순히 시간 비율만 나누지 않는다.

기능 test pass를 장기간 신뢰성 보장으로 표현하지 않는다.
