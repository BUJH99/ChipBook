실제 구현과 simulation model이 이 의도를 어떻게 반영하는지 확인해야 한다. Power-aware 검증에서는 상태 전환과 X 전파, 경계 셀 동작을 함께 본다.

계산·동작 예

Off domain의 출력이 X가 될 때 isolation이 적용되어 on domain에 정의된 값이 전달되는지 확인한다. Save/restore 누락도 regression에 포함한다.

코드와 동작

# UPF concept fragment; supply, state and library bindings are project inputs.
create_power_domain PD_AON  -elements {uPowerCtrl}
create_power_domain PD_CORE -elements {uCore}
set_isolation ISO_CORE -domain PD_CORE -clamp_value 0 -applies_to outputs
# Connect the isolation control, supply sets, power states and retention policy
# using the command revision supported by the selected UPF tool flow.
