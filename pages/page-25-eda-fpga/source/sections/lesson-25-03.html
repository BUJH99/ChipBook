Seed와 입력, model·tool version을 보존해야 같은 실패를 재현할 수 있다. 파형은 시간 단위와 X/Z, event 순서를 함께 읽는다.

계산·동작 예

최초 error와 관련 scope를 찾은 뒤 해당 입력 sequence를 줄여 최소 재현을 만든다. 최종 timeout 메시지만 보는 것보다 앞선 protocol 위반을 찾는 것이 중요하다.

코드와 동작

# 예제: 도구와 언어 지원에 맞게 파일 목록을 지정
iverilog -g2012 -s tb_top -o sim.out rtl.sv tb.sv
vvp sim.out
# log의 exit code와 PASS/FAIL, waveform을 함께 확인

Waveform에 보이는 마지막 증상을 원인으로 단정하지 않는다.

실패를 최소 입력으로 재현한다.
