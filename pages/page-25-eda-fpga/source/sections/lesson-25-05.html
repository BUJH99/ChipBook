같은 RTL도 ASIC standard cell과 다른 resource로 mapping된다. Clocking, memory inference, pin과 IO standard 및 timing constraint를 확인한다.

계산·동작 예

Multiplier를 DSP에 mapping하는 경우와 LUT logic으로 구현하는 경우의 resource·timing을 비교한다. 단순 gate count 비교로 ASIC 결과를 예측하지 않는다.

RTL 시뮬레이션 통과만으로 board pin과 clock constraint가 올바르다고 가정하지 않는다.

ASIC과 FPGA의 구현 차이를 설명한다.
