Script는 입력 검증, exit status와 결과 파일 경로를 명시해야 한다. 구조화된 결과를 사용하면 log의 우연한 문구 변화에 덜 취약하다.

계산·동작 예

여러 corner의 timing summary를 읽어 mode·corner·slack·unconstrained count를 표로 만든다. 누락된 run을 0 violation으로 처리하지 않고 별도 실패로 표시한다.

코드와 동작

import csv
from pathlib import Path

rows = list(csv.DictReader(Path('timing.csv').open()))
required = {'mode', 'corner', 'slack_ns', 'status'}
assert rows and required <= rows[0].keys()
for row in rows:
    if row['status'] != 'complete':
        raise RuntimeError(f"Incomplete run: {row['mode']} / {row['corner']}")
    slack = float(row['slack_ns'])
    print(row['mode'], row['corner'], 'PASS' if slack >= 0 else 'VIOLATION', slack)

실행 명령이 끝났다는 사실과 필요한 산출물이 정상 생성됐다는 사실을 구별한다.

입력과 결과를 반복 생성하고 실패를 감지한다.
