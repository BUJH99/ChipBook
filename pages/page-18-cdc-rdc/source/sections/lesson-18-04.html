상대 pointer를 Gray code 등으로 전달해 full/empty를 판단한다. Pointer wrap과 reset 관계, memory port의 동작을 함께 정의해야 한다.

계산·동작 예

Depth 4에서 다섯 번째 write를 막고, read 후 공간이 다시 생기는 과정을 본다. 실제 async 구현에서는 상대 pointer가 동기화 지연 뒤 반영되므로 flag가 보수적으로 유지될 수 있다.

코드와 동작

// Binary pointer is used for memory indexing; Gray crosses the domain.
assign PtrWrBin_d  = PtrWrBin + (WriteValid && WriteReady);
assign PtrWrGray_d = (PtrWrBin_d >> 1) ^ PtrWrBin_d;
// Synchronize the Gray pointer before computing the remote empty/full view.
// This fragment does not include the full/empty equation or physical skew constraints.

브라우저의 논리 queue 동작을 아날로그 metastability까지 검증한 것으로 해석하지 않는다.

wrap·동시 read/write·reset에서 데이터 순서를 보존한다.
