짧은 pulse는 목적 clock에서 보이지 않을 수 있어 pulse stretching, toggle 또는 handshake가 필요하다. 원천·목적 clock 속도뿐 아니라 event 사이 간격도 고려한다.

계산·동작 예

10 ns 폭 pulse를 20 ns 주기의 목적 clock로 관측하면 위상에 따라 놓칠 수 있다. Event를 toggle로 바꾸면 변화가 sampling될 때까지 상태를 유지할 수 있지만 event rate 제한이 남는다.

코드와 동작

(* ASYNC_REG = "TRUE" *) logic Event_d1, Event_sync;
always_ff @(posedge iClkDst or negedge iRstn) begin
    if (!iRstn) begin
        Event_d1   <= 1'b0;
        Event_sync <= 1'b0;
    end else begin
        Event_d1   <= iEvent_cdc;
        Event_sync <= Event_d1;
    end
end
// Single-bit level only. Pulse width and reset release need separate contracts.

모든 single-bit signal에 동일 2FF를 붙이면 사건의 수가 보존된다고 가정하지 않는다.

짧은 pulse가 유실되는 조건을 찾아 대안을 고른다.
