Inductorv = L·di/dt전류 변화가 전압을 만든다. 실제 저항·포화·기생 성분은 별도다.

미분과 적분변화율 dV/dt, 누적 ∫i dt급격한 edge의 전류와 capacitor에 축적된 전하를 연결한다.
RC 응답τ = RC, V(t) = VDD(1−e^(−t/τ))단일 집중 RC 충전 모델. 10–90% rise time은 ln(9)τ.
주기와 주파수T = 1/f500 MHz는 2 ns. MHz·ns를 혼용할 때 10의 지수를 확인한다.
Dynamic powerP = αCV²f활동도 정의, 등가 부하와 전압 조건. Leakage와 short-circuit은 별도.

평균과 분산μ = E[X], σ² = E[(X−μ)²]평균은 tail와 worst case를 대신하지 않는다. Sampling 조건을 기록한다.

dB10log10(P2/P1), 20log10(V2/V1)전압 비를 전력 비로 바꿀 때 impedance 조건이 같아야 한다.

Verilog / SV RTL
Bit 폭·signedness·reset·clock·합성 가능성부터 확인한다. Blocking/nonblocking은 event 의미와 회로 의도에 맞게 사용한다.
SV 검증
Class·constraint·interface·clocking·SVA의 관측 시점을 명시한다. Randomization 실패와 objection 균형을 검사한다.
C와 MMIO
실제 플랫폼의 register 접근·barrier·DMA API를 사용한다. Volatile만으로 cache와 bus ordering을 해결하지 않는다.
Python
입력과 출력 schema, 단위, exit code와 예외 처리를 명시한다. Missing result를 정상 0으로 바꾸지 않는다.
Tcl
EDA collection·scope·pattern을 확인하고 빈 collection을 경고로 처리한다. 예외 제약은 설계 근거와 연결한다.
Shell / Git
Working directory와 tool version을 고정하고 실패 exit code를 보존한다. Source와 generated artifact를 분리한다.
// 순차 상태와 다음 상태를 구분하는 예
always_comb begin
    next_count = count;
    if (enable) next_count = count + 1'b1;
end
always_ff @(posedge clk or negedge reset_n) begin
    if (!reset_n) count <= '0;
    else          count <= next_count;
end

이 코드는 개념 예제입니다. 실제 IP의 width·overflow·reset 해제·clock 제약을 추가로 정의합니다.

Liberty·SPEF·UPF 조각은 필드를 읽기 위한 축약 예제이며 완전한 tool 입력 파일이 아닙니다. 실제 실행에는 library·net·supply와 분석 조건을 모두 연결합니다.
