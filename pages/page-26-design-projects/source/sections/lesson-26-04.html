Boot image와 address map, register definition을 일치시킨다. 최소 smoke test는 memory와 실제 peripheral의 관측 가능한 결과까지 이어진다.

계산·동작 예

ROM 진입 → SRAM 검사 → UART 출력 → DMA 전송 → IRQ 확인 순으로 test를 늘린다. 각 단계의 실패가 어디에서 관측되는지 정의한다.

코드와 동작

python mini_soc.py
python mini_soc.py --fault
# 정상: UART=OK, destination=0..31, IRQ cleared
# 오류: DMA error status 관측 후 IRQ cleared

실행 가능한 예제

CPU·SRAM·UART·DMA·IRQ 실행 모델DMA–FIFO 통합 TOPDMAFIFO예제 실행 도구

IP simulation의 성공을 연결 검증과 firmware 실행 검증으로 대신하지 않는다.
