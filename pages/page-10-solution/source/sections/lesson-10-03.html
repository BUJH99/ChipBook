주소 공간과 주변장치 선택

주소 decoder는 범위·alignment·겹침을 검사해 하나의 요청이 정확히 한 target에 도달하도록 합니다. 아래 예제는 32-bit 주소 공간의 일부를 사용하며 영역 높이는 실제 용량 비례가 아닙니다.

주소 · bit field · byte strobe

DMA 주변장치의 base는 0x4000_0000입니다. Offset, reset 값, 접근 속성, side effect를 RTL과 driver가 같은 의미로 사용해야 합니다.

32-bit byte lane 선택

C와 RTL의 access 의미를 맞추기

RW는 선택한 byte를 갱신하고, RO는 쓰기로 바뀌지 않으며, W1C는 선택한 byte 안에서 1을 쓴 bit만 지웁니다. 아래는 한 access 속성으로 구성된 32-bit register의 독립 예제입니다. 위 STATUS처럼 mixed access인 register는 field별 규칙을 적용합니다.

  • W1C STATUS를 read-modify-write하면 다른 pending bit까지 지울 수 있습니다.
  • 동시 event set과 software clear의 우선순위를 정의합니다.
  • SRC / DST는 bus address이며 CPU virtual pointer와 같다고 가정하지 않습니다.
  • volatile만으로 cache synchronization과 bus ordering이 해결되지는 않습니다.
