SoC의 부팅 경로와 소프트웨어 계층

CPU는 reset vector의 ROM 코드를 실행해 최소 환경을 구성하고 다음 image를 선택·검사합니다. 예제에서는 외부 flash의 image를 SRAM에 적재한 뒤 제어를 넘깁니다. 플랫폼에 따라 XIP나 DRAM 적재 경로를 사용할 수 있습니다.

코드와 실제 동작

Start 전에 이전 동작이 끝났는지 확인하고 descriptor를 publish한 뒤 doorbell을 기록합니다. 완료 대기는 제한 시간을 두며 실패 시 status·잔여량·오류 원인을 보존합니다.

/* 교육용 API: 실제 플랫폼의 MMIO/DMA API로 구현 */
prepare_descriptor(&desc, src_bus_addr, dst_bus_addr, length);
dma_sync_for_device(&desc);
write_register(DESC_ADDR, descriptor_bus_addr);
write_register(CTRL, START | IRQ_ENABLE);

if (!wait_for_completion_with_timeout(deadline)) {
    stop_dma_and_wait_idle();
    record_status_and_remaining_bytes();
    return ERROR_TIMEOUT;
}
dma_sync_for_cpu(output_buffer);
return verify_output();

교육용 API 예제입니다. DESC_ADDR는 이 장의 확장 register map에서 offset 0x14이며, CTRL은 0x00입니다. 실제 OS·CPU의 MMIO / DMA API로 구현합니다. 완료 응답 후에도 error status를 판별해야 합니다.
