Isolation과 retention의 역할

전력 domain이 꺼지면 해당 영역의 출력과 저장 상태를 신뢰할 수 없습니다. Isolation은 살아 있는 영역에 불확정 출력이 전달되는 것을 막고, retention은 지정한 state를 보존합니다.

Always-on domain

전력 제어·wake 감시·다른 domain의 제어

Isolation boundary

유효하지 않은 switched output을 clamp

Level shifter

서로 다른 전압 domain의 signal 변환

Switched domain

Power switch로 공급 제어 · 선택한 state retention

그림은 기능 배치 개념도입니다. Isolation 위치·방향·clamp 값과 level shifter의 필요 여부는 실제 전압·전원 상태에 맞춰 정의합니다.

Clock · reset · power 상태 전환

Power-off 예제는 새 요청 차단 → 진행 작업 완료 → 상태 저장 → isolation → clock 차단 → power-off 순서입니다. 복귀 때는 전원과 clock을 안정시킨 뒤 저장 상태와 reset을 복구하고, 출력이 유효해진 후 isolation을 해제합니다.

Clock gating은 공급 전원을 끄지 않습니다. Power gating과 동일한 leakage 절감 효과로 취급하지 않으며, retention을 선택하지 않은 register가 자동으로 보존된다고 가정하지 않습니다.
