데이터 이동과 처리 경로

CPU는 작업을 설정하고 DMA는 memory와 accelerator 사이에서 데이터를 옮깁니다. 시스템 latency는 연산뿐 아니라 입력·출력 전송, queue, 동기화와 software overhead를 포함합니다.

예시 병목 분석과 시간 예산

입력 byte·출력 byte·연산량을 고정하고 지속 대역폭과 연산 상한으로 최소 시간을 계산합니다. 예제의 peak 수치를 실제 측정 sustained 성능으로 오해하지 않습니다.

단계별 자원 점유와 overlap

동일한 tile들을 load·compute·store로 처리합니다. 아래 overlap은 독립 load engine과 store engine, 두 buffer를 가정하며, 같은 buffer를 재사용하기 전에 이전 store가 끝나야 합니다.

세 engine이 실제로 같은 memory port를 공유하면 표시한 대역폭을 동시에 사용할 수 없습니다. 이 그림은 독립 자원이라는 가정 아래의 시간 예산이며, 실제 시스템은 경합을 포함해 다시 측정합니다.
