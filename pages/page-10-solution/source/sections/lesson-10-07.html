SoC의 Clock / Reset 통합 구조

Reference clock에서 만들어진 clock을 각 domain에 분배하고, 전원·clock 안정 조건에 따라 reset을 해제합니다. Clock source, mux, divider, PLL lock과 domain별 reset 규칙을 명시합니다.

Clock stable과 reset release

비동기 assert는 상태를 빠르게 초기화할 수 있지만 deassert는 목적 clock domain에서 동기화합니다. 아래는 power-good과 lock이 모두 유효한 뒤 두 목적 clock edge를 거쳐 reset을 해제하는 예제입니다.

파형은 edge 순서를 위한 정규화 시간축입니다. 24 MHz와 800 MHz의 실제 주기 비율을 축척으로 표현하지 않습니다. Memory training과 bus 준비는 reset 해제 이후의 별도 조건입니다.

Domain 조건별 reset 결과

Bypass는 안정된 reference를 전제로 하며 PLL lock을 요구하지 않습니다. 필수 clock이 없거나 reset 요청이 있으면 해당 domain의 reset은 유지됩니다.
